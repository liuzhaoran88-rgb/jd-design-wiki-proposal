3.1 普通底导组合

本页尝试用 Markdown 内容生成一份可读 HTML 规范，并优先通过设计稿变量与节点结构重建可交互组件。当前聚焦普通底导组合，不包含 Joy Agent 特殊形态。

打开交互演示台

定义

普通底导组合用于承载底部一级导航入口。组件外层保持 375 DP 宽的页面基准，内部使用 351 x 52 DP 的 Liquid Glass 容器承载坑位。不同数量配置不改变外层宽度，只改变内部坑位的均分宽度或替换中部强化入口。

结构

层级尺寸 / 规则说明
外层整栏375 x 69/70对齐移动端页面宽度，底部预留 17 DP。
主容器351 x 52左右各 12 DP，圆角 16。
内边距4 DP坑位放置在玻璃容器内。
坑位间距8 DP普通坑位之间保持 8 DP；灵动岛与相邻普通坑位之间也保持 8 DP。
普通坑位44 DP 高图标 20 DP，文本 10 号字，图文间距 4 DP。
选中坑位44 DP 高背后可出现 12 DP 圆角的选中底板。

视觉状态

默认态使用普通字重文本，选中态使用 color_primary，文本字重提升到 600。玻璃容器需要区分浅色背景与暗色背景两套参数，不应混用。

浅色背景下，Liquid Glass 使用 模式=日间，Zero 源参数为 rgba(245,245,245,.60) 叠加 #262626，混合模式为 color-dodge, normal；HTML 演示按截图观感叠加洁净白色玻璃视觉层，避免浏览器混合后出现灰脏。选中坑位底板为 #F2F4F7。

暗色背景下，Liquid Glass 使用 模式=暗黑，底层透明度为 .60，背景层为 rgba(255,255,255,.06)、rgba(0,0,0,.60)、#CCCCCC，混合模式为 color-burn, normal, normal；选中坑位底板为 #14171A。

普通坑位文案最多展示 4 个汉字，超出需业务侧改短，不建议自动缩小字号。单个底导之间保持 8 DP 间距；灵动岛与相邻普通坑位之间同样保持 8 DP 间距。灵动岛是独立原子，不作为普通坑位等宽分配；日常/运营宽度为 131，大促宽版为 144，且只能配置在中间强化位，不允许配置到两侧坑位。
