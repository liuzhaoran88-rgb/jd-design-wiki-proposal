1🎨 颜色

色彩 token 体系 — 中性 / 品牌 / 反馈 / 服务等 9 类

👉 这一类 token 是干什么的?

色彩 Token · V16.0

V16.0 色彩体系是 3 层架构：组件 → Token（语义） → Atom（原子色板）→ Hex/Dark variant。

本文档定义 L2 Token 层（34 个语义 token，10 大组）。L1 Atom 层在 tokens.json#atom 维护；hex 与 dark 值待从平台色板批量提取。

📖 完整 token 列表 / 命名规则 / 使用边界 → tokens/color.md (GitHub)

变化 V15.0 V16.0
架构 Token → Hex 直给（混层） Token → Atom → Hex（3 层解耦）
命名 color.brand.primary（dot 层级） color_primary（snake 平铺）
Error/Danger semantic.danger = brand.primary = #ff0f23（共色，wash 区分） color_error 独立色族 errorred（彻底拆开）
Service functional.service-gold-{1..7,subtle,strong} 9 个零散 color_service{,_bground,_border,_text} 四件套

2✍ 文字

字体 / 字号 / 字重 / 行高 token,基于苹方 / 京东正黑

👉 这一类 token 是干什么的?

字体 Token · V16.0

V16.0 字体 token 三层：Family（字族）× Size（字阶）× Weight（字重）。组件层引用 Role 组合 token（如 font_size_14_400 = pingfang 14pt regular）。

间距 Token · V16.0

V16.0 间距体系 沿用 V15 的双梯度（导购型 / 平台型） + 基量 4，但未在「语义化统一」里出现新的 spacing token frame。空间布局 1/2/3 规范页（6:3）里以「DP 数值 + 用法描述」形式呈现，token 命名沿用 V15 即可。

6➖ 线条

分割线 / 描边 token

👉 这一类 token 是干什么的?

线 Token · V16.0 🚩 全新独立 foundation

V16.0 新增「线」作为独立 foundation。V15.0 没有线宽 token —— 只有 color.neutral.border.default = #00000014（颜色），线宽靠 CSS 默认 1px。

V16 把线宽显式 token 化，针对高密屏（2x/3x）做了精细化处理。

7📐 布局

页面布局规范(空间布局 1/2/3)

👉 这一类 token 是干什么的?

布局 · V16.0

V16 布局 = Z 轴 4 层级 + 2 种页面框架（卡片式 / 平铺式） + 双梯度间距（导购型 / 平台型）。

数值规范见 spacing.md；本文档讲用法 / 决策依据。

📖 完整 token 列表 / 命名规则 / 使用边界 → visual/layout.md (GitHub)

7.1 完整 token 表(摘录第一张关键表)

层级 用途 交互特征 视觉特征
背景层 氛围 / 大促换肤 无交互，不可被位移 常态：中性背景色；大促：换肤烘托氛围；上滑后氛围适应
内容层 当前场景核心信息 + 核心任务 滑动、操作；被全局控制层覆盖 容器结构与背景层边界清晰；滑动符合物理运动逻辑
全局控制层 全局操作 + 导航功能 始终可见 / 浮于内容之上 顶导 / 底导 / 悬浮按钮
临时任务层 弹层 / 弹窗 / Toast 进入时遮挡下层 用材质（Liquid / Frosted Glass）做层级感 — 见 materials.md
